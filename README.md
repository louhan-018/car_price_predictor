# 🚗 Car Price Predictor

An end-to-end **Machine Learning web application** that predicts the **price of a used car** based on user inputs such as company, model, year, fuel type, and kilometers driven.  
The project uses **Flask** for the backend, **scikit-learn** for the ML model, and a **modern glassmorphism UI** for the frontend.

---

## 🔗 Live Demo
👉 https://car-price-predictor-l4ww.onrender.com/

---

## 📌 Features
- 🔍 Predicts used car prices instantly
- 🧠 Machine Learning model trained using **Linear Regression**
- 🧩 Handles categorical data using **OneHotEncoder**
- 🌐 Flask-based web application
- 🎨 Modern **glassmorphism dark UI**
- ⚡ AJAX-based prediction (no page reload)
- 📱 Fully responsive design
