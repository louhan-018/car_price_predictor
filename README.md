# 🚗 Car Price Predictor

A Machine Learning-powered web application that predicts the selling price of a used car based on various input features such as brand, model, manufacturing year, fuel type, transmission, mileage, and more.

Built with **Python**, **Streamlit**, and **Scikit-learn** for an interactive and user-friendly experience.

---

## 📌 Features

- 🔍 Predicts the price of used cars instantly
- 🤖 Machine Learning regression model
- 🎨 Interactive web interface using Streamlit
- 📊 Data preprocessing and feature engineering
- ⚡ Fast and lightweight
- 📱 Responsive UI

---

- Brand
- Model
- Year
- Fuel Type
- Transmission
- Seller Type
- Owner
- Mileage
- Engine
- Max Power
- Seats
- Kilometers Driven
